# ゆめいろタウン

小学2年生向けの おうち用 学習アプリ（iPad / iPhone の Safari で うごく PWA、オフライン対応）。
HTML / CSS / JavaScript だけで できていて、ビルドは いりません。

このリポジトリは **オリジナルキャラ版**（Netlify に おいている版）です。
ちいかわの絵は ネットに あげないので、ここには いれません（`charset.js` は からっぽ。`.gitignore` で `charset/` なども よけています）。

## Macでためす
1. このフォルダで `python3 -m http.server 8000`
2. Safari で `http://localhost:8000` を開く（終わるときは Control + C）
3. 「表示 → レスポンシブ・デザイン・モード」で iPad / iPhone サイズにすると 実機に近い見た目で確認できます

## ファイルを ふやすとき
- `index.html` の script と `sw.js` の `FILES` に たす
- `sw.js` の `CACHE`（いまは `yumeiro-v20`）の ばんごうを 1 あげる（あげないと iPhone に あたらしい版が とどかない）

## あそびかた
- **タウン**：いきたい建物をタップすると、パートナーが歩いていって中に入ります。地面をタップするとそこまで歩きます。ほかの2人もうろうろしています
- 最初にパートナーを1人えらぶ（あとの2人はお客さん・店員さんとして登場）
- **ゆめいろパティスリー**：注文ごとに ① 九九（トッピングの数）② かさ（L・dL・mL）③ 長さ（cm・mm）★グラムのチャレンジ（パスできる）。1こ 50円 ＋ 1回で正解ボーナス 10円ずつ ＋ チャレンジ 20円
- **おかいもの**：ごはん・ふく・かぐを3こまでかごへ → 合計を計算 → お金を出す → おつりを計算
- **おへや**：かったごはんをあげる（もぐもぐ）、ふくを着せかえ、かぐがお部屋にならぶ
- まちがえるとヒントが出て、3回目で答えを教えてくれます

## おうちのひと メニュー
タウン画面左上の ⚙️ を **ながおし**（1秒ちょっと）。
- キャラの名前変更（娘さんと決めた名前に）／パートナーの選びなおし
- 九九で出す段、グラムチャレンジ、効果音、読み上げ のオン・オフ
- 分野ごとの正解率（1回目で正解した数／全部）
- お金の調整、データのリセット

データはその端末の中（ブラウザ）だけに保存されます。

## じぶんの え（iPhone / iPad の なかだけ）
- 「おうちのひと」→「じぶんの えを つかう」で、写真から キャラの絵（ふつう・にこにこ・しょんぼり）を えらべます。
- 絵は その端末の IndexedDB にだけ ほぞん。ネットには あがりません。まわりの白を とうめいにして、よはくを きって 512px に ととのえます。
- ネットに おく版（Netlify など）は オリジナル版だけ。Mac の `アプリ/yumeiro-netlify/` が そのまま おける フォルダです。

## Netlify に おく
1. Mac で https://app.netlify.com/drop を ひらき、無料アカウントを つくる（アカウントなしだと 1じかんで きえる）
2. `yumeiro-netlify` フォルダを ドラッグ＆ドロップ
3. でてきた https の URL を iPhone の Safari で ひらき、共有 →「ホーム画面に追加」
4. ホーム画面の アプリから「おうちのひと → じぶんの えを つかう」で 絵を いれる
- 更新するときは Netlify の サイト画面 →「Deploys」に フォルダを もういちど ドロップ。
